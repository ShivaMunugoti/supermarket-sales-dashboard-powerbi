# 📊 Supermarket Sales Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive **Sales Analysis Dashboard** built using Power BI.
It provides insights into revenue, customer behavior, and product performance.

---

## 🚀 Key Features

* 💰 Total Revenue Analysis
* 📦 Total Quantity Sold
* ⭐ Customer Rating Insights
* 🏙 Sales by City
* 💳 Payment Method Analysis
* 🛍 Product Line Performance
* 👥 Gender-wise Sales Distribution

## 📊 Key Insights

* Female customers contribute more to sales
